# 사계절 — 실시간 사계절·날씨 시뮬레이션

알프스 계곡과 캘리포니아의 우리 집, 두 장소의 사계절과 날씨를 실시간으로 보여 주는 WebGL2 시뮬레이션입니다.
외부 라이브러리는 쓰지 않습니다.

## 실행

웹에서 바로 볼 수 있습니다: https://fourseason-lac.vercel.app/

내려받았다면 `index.html`을 더블클릭해 Chrome이나 Safari에서 열면 됩니다. 서버는 필요 없고, 이 파일 하나로 동작합니다.
GPU가 있는 데스크톱이나 최신 휴대폰을 권장합니다. 처음 열면 장면을 한 번 그린 뒤 나타나므로 1~2초 걸립니다.

## 무엇이 보이나

- **장소**: 두 곳이 있고, 언제든 바꿀 수 있습니다. 장소를 바꿔도 계절, 날씨, 시간은 그대로 이어집니다.
  - 알프스 계곡: 높은 곳에서 내려다보는 계곡과 초원, 숲, 산입니다. 처음 열면 이곳이 보입니다.
  - 우리 집: 해 질 녘 캘리포니아의 단층집입니다. 야자수와 참나무가 있고, 흐리거나 비가 오는 저녁에는 창과 현관등, 가로등이 더 환하게 빛납니다.
    캘리포니아는 겨울에도 따뜻해서, 계곡에 눈이 쌓여 있어도 집 마당은 대개 푸릅니다. 눈이 내릴 때만 하얗게 덮였다가
    몇 분 뒤 녹습니다.
- **계절**: 1년이 20분에 흘러서, 기본 속도에서는 계절이 약 5분마다 바뀝니다. 시작 계절은 오늘 날짜를 따릅니다.
  - 봄: 연두빛 풀과 들꽃이 나고, 눈이 녹아 설선이 올라갑니다. 집 앞 과일나무에는 꽃이 핍니다.
  - 여름: 짙은 초록입니다.
  - 가을: 금빛 낙엽송과 황갈색 초원입니다. 집 앞 나무들도 단풍이 들고, 11월 말에는 잎이 집니다.
  - 겨울: 계곡까지 깊은 눈이 덮입니다.
- **날씨**: 맑음, 구름(흘러가는 적운과 그 그림자), 흐림, 안개, 비, 뇌우, 눈, 폭설이 있습니다.
  - 계절에 맞춰 무작위로 바뀌고, 한 번 바뀌는 데 약 1분이 걸립니다. 구름이 먼저 끼고, 그다음 비나 눈이 내립니다.
  - 기온에 따라 비가 되기도 하고 눈이 되기도 합니다. 땅에는 눈이 쌓이고 녹으며, 비가 오면 젖습니다.
  - 뇌우는 주로 늦봄과 여름에 옵니다. 먹구름이 낮게 깔리고, 굵은 비와 돌풍 속에 번개가 칩니다.
- **자연 현상**: 지진과 산불 연기를 직접 일으킬 수 있습니다. 번개는 뇌우가 올 때 칩니다.
  - 지진: 화면이 흔들리고, 흙먼지가 일고, 포장된 땅에 금이 갔다가 1분쯤 지나면 사라집니다. 집에서는 불빛이 깜빡입니다.
  - 산불 연기: 멀리서 난 산불의 연기로 하늘이 주황빛으로 물들고 해가 붉어지며, 재가 날립니다. 3분쯤 지나면 걷힙니다.
    비가 오면 연기가 옅어집니다.
  - '가끔 자동으로'를 켜면 지진과 산불 연기가 가끔 저절로 일어납니다. 산불은 늦여름과 가을에만 납니다.
- **바람**: 평소에는 자연스럽게 무작위로 붑니다.
  - 마우스 왼쪽 버튼을 누른 채 드래그하거나 휴대폰에서 손가락으로 쓸면, 그 방향으로 바람이 일었다가 천천히 잦아듭니다.
  - 버튼을 누르지 않고 마우스를 움직이기만 하면 아무 변화가 없습니다.

## 조작

화면에는 오른쪽 아래의 반투명 아이콘 하나만 있습니다. 아이콘 모양은 계절 따라 꽃, 해, 잎, 눈꽃으로 바뀝니다.
아이콘을 누르면 설정 창이 열립니다.

| 항목 | 내용 |
|---|---|
| 장소 | 알프스 계곡 · 우리 집. 고르면 그 장소가 새로 그려지며 나타납니다. |
| 계절 | 자동 · 봄 · 여름 · 가을 · 겨울. 계절을 고르면 약 1분에 걸쳐 그 계절로 바뀐 뒤 머뭅니다. |
| 시간 흐름 | 0.25× ~ 8×. '1년 = 20분'처럼 한 해의 길이가 표시됩니다. |
| 날씨 | 자동 · 맑음 · 구름 · 흐림 · 안개 · 비 · 뇌우 · 눈 · 폭설. 날씨를 고르면 약 1분에 걸쳐 바뀐 뒤 그대로 유지됩니다. |
| 눈·비의 양 | 강수량을 조절합니다. |
| 자연 현상 | 지진 · 산불 버튼, 그리고 '가끔 자동으로' 스위치입니다. |

데스크톱에서는 키보드 ← / → 로도 장소를 바꿀 수 있습니다(설정 창이 닫혀 있을 때).
설정 창은 바깥을 누르거나, Esc를 누르거나, 잠시 아무 조작도 하지 않으면 닫힙니다.

## 테스트용 URL 파라미터

| 파라미터 | 의미 |
|---|---|
| `?scene=valley\|house` | 해당 장소로 시작합니다(기본은 알프스 계곡). |
| `?season=spring\|summer\|autumn\|winter` | 해당 계절로 시작해서 그 계절에 머뭅니다. |
| `?weather=clear\|cumulus\|overcast\|fog\|rain\|thunder\|snow\|blizzard` | 해당 날씨로 시작해서 그 날씨를 유지합니다. |
| `?event=quake\|wildfire\|strike` | 시작하자마자 지진, 산불 연기, 번개 한 번을 일으킵니다(맑은 날의 번개는 멀리서 번쩍이는 마른번개입니다). |
| `?speed=4` | 시간 흐름 배속입니다. |
| `?t=300` | 300초가 흐른 상태로 시작합니다. |
| `?seed=N` | 난수 시드입니다. 같은 시드와 같은 `t`면 같은 상태가 됩니다. |
| `?ui=0` | 아이콘과 안내 문구를 숨깁니다. |

예: `?season=autumn&weather=fog`는 가을 운해, `?scene=house&weather=rain`은 비 오는 저녁의 우리 집을 보여 줍니다.

브라우저 콘솔에서는 `window.snowSim`을 쓸 수 있습니다. `state()`, `setScene()`, `setSeason()`, `setWeather()`,
`trigger('quake' | 'wildfire' | 'strike')`, `hazardsAuto`, `speed`, `amount`, `advance(t)`가 있습니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 공개 버전입니다. `app/`을 파일 하나로 묶은 것입니다. |
| `app/` | 소스입니다. 일반 스크립트 40개로 되어 있습니다. 구조는 `app/ARCHITECTURE.md`, 테스트는 `app/tests/`에 있습니다. |
| `tools/build.mjs`, `tools/release.sh` | `app/`을 파일 하나로 묶어 `index.html`로 내보냅니다. |
| `releases/phase1-snow.html` | Phase 1(눈 내리는 계곡) 완성본입니다. Phase 2 완성본은 git 커밋 `f311fc6`에 있습니다. |
| `docs/` | Phase 2·3 계획서와 Phase 1 코드 분석 문서입니다. |
| `variants/` | 초기에 비교하려고 만든 시안 3종입니다. |

## 개발

```bash
sh app/tests/all.sh
```

모든 테스트를 실행합니다. 헤드리스 Chrome, Python3(PIL), git이 필요합니다. 계곡이 Phase 2와 픽셀 단위로 같은지 보는
테스트는 git 커밋 `f311fc6`의 `app/`을 기준으로 씁니다.

```bash
sh tools/release.sh
```

`app/`을 파일 하나로 묶어 루트의 `index.html`을 갱신합니다.
