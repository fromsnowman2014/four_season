# 설경 — 실시간 눈 시뮬레이션

알프스 계곡 위로 눈이 내리는 실시간 WebGL2 시뮬레이션입니다. 외부 라이브러리 없이 동작합니다.

## 실행

웹에서 바로 보기: https://fromsnowman2014.github.io/four_season/

내려받은 경우에는 `index.html`을 더블클릭해 Chrome이나 Safari에서 열면 됩니다. 서버는 필요 없습니다.
GPU가 잘 받쳐 주는 데스크톱 브라우저를 권장합니다. 첫 화면은 장면을 한 번 그린 뒤 나타나서 1~2초 걸립니다.

## 조작

- **마우스 이동**: 바람이 생깁니다. 커서 주변의 눈송이가 밀려납니다.
- **오른쪽 아래 눈꽃 아이콘**: 클릭하면 설정 창이 열립니다.
  - 눈의 양
  - 폭설 일으키기
  - 자동 폭설
  - 쌓인 눈 초기화

  설정 창은 바깥을 클릭하거나, Esc를 누르거나, 6초 동안 아무 조작이 없으면 닫힙니다.

## 테스트용 URL 파라미터

| 파라미터 | 의미 |
|---|---|
| `?t=200` | 200초가 흐른 상태로 시작합니다. 쌓인 눈과 폭설 일정이 그만큼 진행됩니다. |
| `?cover=0..1` | 쌓인 눈의 양을 지정합니다. |
| `?storm=1` | 처음부터 폭설로 시작합니다. `?storm=0`은 자동 폭설을 끕니다. |
| `?seed=N` | 난수 시드를 지정합니다. |
| `?wind=X,Z` | 초기 바람을 m/s 단위로 지정합니다. |
| `?ui=0` | UI를 숨깁니다. 깨끗한 화면을 캡처할 때 씁니다. |

브라우저 콘솔에서는 `window.snowSim`으로 상태를 확인하고 바꿀 수 있습니다. `state()`, `setCoverage(v)`, `setStorm(v)`, `reset()`, `amount`, `auto`를 쓸 수 있습니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 현재 공개 버전 (Phase 1: 눈 내리는 알프스 계곡) |
| `releases/phase1-snow.html` | Phase 1 완성본 보관용 사본 |
| `docs/` | Phase 2(계절·날씨) 계획서와 코드 분석 문서 |
| `variants/` | 초기 비교용 시안 3종 (mesh3d / raymarch / matte). 최종본은 raymarch 시안을 바탕으로 했습니다. |

Phase 2(사계절과 날씨)는 개발 중이며, 완성되면 이 저장소에 올라옵니다.
